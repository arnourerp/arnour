# Arnour

Static site (HTML/CSS/JS) for arnour.com. Netlify publishes this repository as-is.

- `index.html`, `css/`, `js/`, `assets/` is the website.
- `js/config.js` holds the public Supabase URL and publishable key (safe to publish).
- `supabase/` holds the database SQL (001 schema, 002 sample data, 003 community, 004 community samples).
